# MBTI Character Images

Put your character images in this folder using these exact file names:

- `INTJ.svg`
- `INTP.svg`
- `ENTJ.svg`
- `ENTP.svg`
- `INFJ.svg`
- `INFP.svg`
- `ENFJ.svg`
- `ENFP.svg`
- `ISTJ.svg`
- `ISFJ.svg`
- `ESTJ.svg`
- `ESFJ.svg`
- `ISTP.svg`
- `ISFP.svg`
- `ESTP.svg`
- `ESFP.svg`

Recommended size: transparent SVG or PNG, at least `900x1200` px.

The app automatically loads `/characters/{TYPE}.svg`. If you prefer PNG, change `getCharacterImagePath` in `src/App.jsx` to return `/characters/${type}.png`.
